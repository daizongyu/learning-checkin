# Learning Check-in

**简单 • 本地 • 隐私优先**

一个帮助你养成每日学习习惯的打卡工具。所有数据都存储在你的设备上，完全隐私保护。

---

## 🎯 这是什么？

Learning Check-in 是一个**零门槛**的学习打卡助手：

- ✅ **无需技术知识** - 只需要自然语言对话
- ✅ **完全本地** - 数据存在你的电脑上，不上传云端
- ✅ **智能提醒** - 根据时间、季节调整语气的贴心提醒
- ✅ **跨平台** - Windows、Linux、macOS 都能用
- ✅ **零依赖** - 只需要 Python，无需安装其他东西

---

## 🚀 快速开始

### 第一步：开始打卡

告诉系统你想开始打卡，比如：

```
我想开始学习打卡
```

系统会为你介绍打卡规则，并帮你记录第一次打卡。

### 第二步：每天打卡

完成学习后，简单说一句：

```
打卡
```

或者

```
今天学完了，打卡完成！
```

### 第三步：查看进度

随时询问：

```
我的打卡情况怎么样？
```

系统会告诉你连续打卡天数和总打卡次数。

---

## 📝 打卡规则

### 默认规则

1. **每天打卡一次**
   - 完成学习后告诉系统"打卡"即可
   - 时间不限，完成就能打

2. **智能提醒**
   - 如果忘记打卡，系统会在 9:00、17:00、20:00 提醒你
   - 已经打卡就不会打扰你
   - 提醒语气会根据时间调整（晚上更"严厉"）

3. **连续统计**
   - 自动记录连续打卡天数
   - 7 天、30 天、100 天有特殊祝贺

4. **灵活调整**
   - 规则可以根据你的需求修改
   - 随时告诉系统你的想法

### 自定义规则

你可以告诉系统你的偏好，比如：

```
我一般晚上学习，早上不要提醒我
```

```
周末我想休息一下，不用提醒
```

```
我的学习目标是每天阅读 30 分钟
```

系统会帮你更新规则文件。

## 🔒 隐私保护

我们承诺：

- ✅ **不收集个人信息** - 只记录昵称
- ✅ **数据完全本地** - 存在你的设备上
- ✅ **无需联网** - 核心功能 100% 离线
- ✅ **无账号系统** - 不需要注册

数据存储位置：
- **Windows**: `%APPDATA%\learning-checkin\`
- **Linux/macOS**: `~/.learning-checkin/`

---

## 📁 文件说明

安装后会在你的设备上创建以下文件：

```
learning-checkin/
├── user/
│   ├── profile.json    # 你的基本信息
│   ├── history.json    # 打卡历史记录
│   └── RULE.md        # 你的打卡规则
```

你可以随时查看和修改这些文件。

## 🤖 Agent 集成

这个 Skill 是为 OpenClaw 或类似应用设计的，通过 Agent 与用户自然对话。

**Agent 调用示例**:

```python
# 初始化用户
handle_request("init", {"nickname": "Daisy", "language": "zh"})

# 打卡
handle_request("checkin", {"note": "学习了 Python 编程"})

# 查看状态
handle_request("status")

# 生成提醒
handle_request("reminder", {"hour": 9})

# 获取/更新规则
handle_request("rules")
handle_request("rules", {"content": "新的规则内容..."})
```

## ⬆️ 升级

系统会在每天打卡时自动检查新版本。如果有更新，会提示你：

```
💡 有新版本可用：v1.1.0（当前：v1.0.0）
更新：git pull origin main
```

升级不会影响你的打卡记录。

## ❓ 常见问题

### Q: 忘记打卡怎么办？
A: 没关系！第二天继续打卡就好。系统会重新计算连续天数，但历史记录会保留。

### Q: 可以补打卡吗？
A: 目前只支持当天打卡。这样设计是为了培养真实的习惯～

### Q: 如何备份数据？
A: 直接复制 `learning-checkin` 文件夹即可。所有数据都在里面。

### Q: 可以多人使用吗？
A: 每个用户需要独立的配置目录。可以手动管理多个用户档案。
